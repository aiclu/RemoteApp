移动端界面与会话可靠性重构测试版，面向 Android 手机和平板（arm64，Android 8.0+）。

## 更新内容
- 新增设备首页、搜索、收藏、编辑、删除，以及独立设置页。
- 全屏远程会话与鼠标指针/直接触控模式，支持拖拽、滚动、缩放和平移。
- 接入硬件键盘、已提交文本和常用功能键，修复坐标映射及按键释放。
- 隔离会话事件与证书确认，使用最新帧缓冲并处理前后台切换。
- 使用 Android Keystore 保护设备配置加密密钥；密码默认不保存。
- 按主机与端口记录证书信任，证书变化要求重新确认。

## 安装与验证范围
- 附件为调试签名 APK，仅用于测试；不是正式签名发行包，不用于商店上架。
- 本地 Windows 工作区 34 项测试、编译和格式检查通过；发布流水线会再次测试并构建 Android arm64 APK。
- 尚未完成 Android 真机安装、软键盘/中文输入、Keystore 重启恢复、性能和真实 RDP 主机验证，不将这些项目视为通过。
- 调试签名可能与之前安装的 APK 不同，不能保证覆盖安装；卸载会删除应用本地数据。
- 本版本不包含 iOS 工程、微软云服务或 PostgreSQL 同步界面；直接触控使用鼠标事件模拟。
